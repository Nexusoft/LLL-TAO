# Documentation Archive

This folder preserves historical bug write-ups, investigation notes, superseded designs, and PR summaries.

Archive documents are retained for learning and AI-assisted code review, but they may describe past behavior that no longer matches the current code. For current rules and invariants, prefer the living references in [`../reference/`](../reference/), the active architecture docs in [`../architecture/`](../architecture/), and the current operational guides in [`../current/`](../current/).
